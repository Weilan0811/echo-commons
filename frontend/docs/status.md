## 1. 已交付内容

| 层 | 文件 | 说明 |
|---|---|---|

技术栈：React 19.3、TypeScript 5.9、Vite 8.3、React Router 7.18、TanStack Query 5.104、Tailwind CSS 4.3；测试使用 Vitest 5.0、Testing Library 16.3 与 Playwright 1.63。版本由 `package-lock.json` 固定。

## 3. 本轮联调修正的问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 消息显示发送者标识而非名称 | 组件从 `sender` 取 `actor_id` 当名称 | 改用消息携带的 `sender_display` |
| 已读推进无效 | `/read` 只有 `PUT`，此前用它读取 | 改用会话摘要的 `last_read_sequence` 判断未读，`PUT` 只负责推进 |
| 提及提交被拒 | 把展示用身份键当作 `actor_id` 提交 | 提交契约要求的参与者引用 |
| 私聊创建被拒 | 参与者未包含发起人；契约要求一名玩家加一名角色 | 发起人始终加入参与者，私聊对方只列角色 |
| 群聊在列表中显示会话标识 | 摘要没有名称字段 | 记为接口缺口 P1，会话内标题由成员派生 |
| 顶栏缺少世界时间 | 未读取社群详情 | 按社群时区显示 `world_time_utc` |
| 页面加载出现 404 | 没有 favicon | 内联 SVG 图标 |
| 填入的玩家标识一律 404 | 注册接口只写了接口层，界面上没有注册入口 | 入口页先确认玩家是否存在，未注册时提供「注册并进入」 |

## 5. 当前限制

| 事项 | 说明 |
| --- | --- |
| 玩家身份 | 后端没有账户认证，当前主体保存在本地存储，是本地测试身份 |
| 群聊列表名称 | 摘要无名称字段，列表显示会话标识 |
| 管理员端访问边界 | 当前无服务端访问控制，远程真人测试前需按部署方式明确 |
| 实时性 | 只有轮询，没有推送或逐字输出接口；消息轮询 4 秒，会话列表 8 秒 |
| 活动界面 | 阶段五接入，当前不预建渲染结构 |
