# 前端交付与实现状态

更新日期：2026-10-05。

本文件只回答四个问题：现在有什么、验证到哪、还缺什么、当前有哪些限制。技术选择见 [技术选型](01-tech-selection.md)，页面与交互见 [页面与交互设计](03-page-design.md)，交给后端的接口需求见 [接口缺口](02-backend-interface-gaps.md)。实现层面的原因记在代码注释与上述文档中，不写在这里。

## 1. 已交付内容

| 层 | 文件 | 说明 |
|---|---|---|
| 接口层 | `src/api/`（6 个） | 请求发送与错误归一、查询键工厂、健康检查、会话与消息查询、契约生成的类型 |
| 身份 | `src/identity/`（2 个） | 当前主体的单一来源与订阅 hook |
| 纯逻辑 | `src/lib/`（4 个 + 4 个测试） | 角色配色与气泡拆分、消息分组、轮次状态推导、幂等标识 |
| 组件 | `src/components/`（11 个 + 1 个测试） | 头像、气泡、分组、输入器、状态栏、外壳、空状态、错误展示、路由级错误边界 |
| 页面 | `src/app/`、`src/admin/`（7 个） | 用户端主体入口、聊天、游戏列表；管理端首页与连接页 |

临时预览数据已删除，用户端聊天页直接读取后端接口。

技术栈：React 19.3、TypeScript 5.9、Vite 8.3、React Router 7.18、TanStack Query 5.104、Tailwind CSS 4.3；测试使用 Vitest 5.0、Testing Library 16.3 与 Playwright 1.63。版本由 `package-lock.json` 固定。

## 4. 当前限制

| 事项 | 说明 |
| --- | --- |
| 玩家身份 | 后端没有账户认证，当前主体保存在本地存储，是本地测试身份 |
| 端到端聊天验证 | 页面已接入真实接口，但会话、消息与轮次尚未在运行中的后端上验证 |
| 管理员端访问边界 | 当前无服务端访问控制，远程真人测试前需按部署方式明确 |
| 实时性 | 只有轮询，没有推送或逐字输出接口；轮询间隔为 4 秒 |
| 活动界面 | 阶段五接入，当前不预建渲染结构 |
| 后端运行环境 | 本机 `uv` 无法检查托管的 Python 解释器（os error 448），联调使用主工作树启动的后端 |
