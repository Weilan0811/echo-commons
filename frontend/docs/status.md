## 1. 已交付内容

共 40 个源文件已提交，分四层：

| 层       | 文件                                  | 说明                                                                     |
| -------- | ------------------------------------- | ------------------------------------------------------------------------ |
| 接口层   | `src/api/`（5 个）                    | 请求发送、两种错误形状归一、查询键工厂、健康检查、契约生成的类型         |
| 身份     | `src/identity/`（2 个）               | 当前主体的单一来源与订阅 hook                                            |
| 纯逻辑   | `src/lib/`（4 个 + 4 个测试）         | 角色配色与气泡拆分、消息分组、轮次状态推导、幂等标识                     |
| 组件     | `src/components/`（11 个 + 1 个测试） | 头像、气泡、分组、输入器、状态栏、外壳、空状态、错误展示、路由级错误边界 |
| 页面     | `src/app/`、`src/admin/`（7 个）      | 用户端主体入口、聊天、游戏列表；管理端首页与连接页                       |
| 临时数据 | `src/fixtures/`（1 个）               | 预览数据，见第 4 节                                                      |

技术栈：React 19.3、TypeScript 5.9、Vite 8.3、React Router 7.18、TanStack Query 5.104、Tailwind CSS 4.3；测试使用 Vitest 5.0、Testing Library 16.3 与 Playwright 1.63。版本由 `package-lock.json` 固定。

已实现的代码范围：

- `src/api/http.ts`：请求发送与错误归一。后端两种错误形状（`error` 信封与 422 的 `detail` 数组）统一为 `ApiError`，网络不可达单独归类。
- `src/api/queryKeys.ts`：查询键工厂，目前只含健康检查两项。
- `src/app/pages/ConnectionPage.tsx`：读取 `/health/live` 与 `/health/ready`，展示真实后端状态。
- `src/admin/pages/AdminHomePage.tsx`：展示运行状态，并如实列出尚未建设的管理能力。
- `src/api/schema.d.ts`：由后端契约生成。

## 4. 当前限制

| 事项                   | 说明                                                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 用户端使用临时预览数据 | `src/fixtures/previewChat.ts`。会话、消息与轮次均为构造数据，未接入后端。接入后删除该文件并替换 `ChatPage` 中的 `messagesFor` 与 `usePreviewThread`           |
| 可见范围字段的过渡处理 | 后端已决定移除 `visibility` 字段，但本工作树的契约仍列为必填，因此预览数据保留 `visibility: 'conversation'`。契约更新并重新生成类型后，删除预览数据中的该字段 |
| 玩家身份               | 后端没有账户认证，当前主体保存在本地存储，是本地测试身份                                                                                                      |
| 管理员端访问边界       | 当前无服务端访问控制，远程真人测试前需按部署方式明确                                                                                                          |
| 会话发现               | 后端缺少玩家维度的会话列表，见 [接口缺口](02-backend-interface-gaps.md) 的 P1                                                                                 |
| 实时性                 | 只有轮询，没有推送或逐字输出接口                                                                                                                              |
| 后端运行环境           | 本机 `uv` 无法检查托管的 Python 解释器（os error 448），联调使用主工作树启动的后端                                                                            |
