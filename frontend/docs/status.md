## 3. 验证范围

选型阶段没有编写应用代码，因此没有执行组件测试、端到端测试或真实后端联调。

选型依据中的后端事实来自实际代码与文档核对：默认端口 8765、`cors_origins` 默认为空、`server.cors_origins` 段未配置、`openapi.json` 为 OpenAPI 3.1 且 29 个 schema 全部具名、后端未挂载静态文件、开发机 Node 为 20.18.0 且不满足 Vite 7 引擎下限。

## 4. 当前限制

| 事项 | 说明 |
|---|---|
| 玩家身份 | 后端没有账户认证，页面中的玩家选择是本地测试身份 |
| 管理员端访问边界 | 当前无服务端访问控制，远程真人测试前需按部署方式明确 |
| 实时性 | 只有轮询，没有推送或逐字输出接口 |
| 社群与会话发现 | 后端缺少玩家维度的发现接口，见 [接口缺口](02-backend-interface-gaps.md) 的 P1 |
| 活动界面 | 阶段五接入，当前不预建渲染结构 |
