# 后端接口需求与接入状态

更新日期：2026-10-10。

当前接口与响应类型以 [HTTP 参考](../../server/docs/reference/http-api.md)、[管理接口参考](../../server/docs/reference/management-api.md) 和生成的 OpenAPI 为准。页面行为见 [页面与交互设计](03-page-design.md)，请求顺序与恢复规则见 [后端接入指南](../../server/docs/guides/frontend-integration.md)。

## 已实现并接入

| 能力 | 当前行为 |
|---|---|
| 记忆索引响应 | 检查与重建返回正式状态及失败项类型；管理页面展示材料编号、失败原因与尝试次数 |
| 社群封面引用 | 创建与更新保存官方预设引用，查询返回实际引用；社群卡片及聊天头部读取保存值 |
| 图像资产 | 后端提供生成、上传、图片读取与裁剪；前端接入角色插画生成、插画库和头像裁剪 |
| 社群启停 | 用户社群页与管理清理页通过正式接口保存状态，提交当前版本 |
| 测试社群清理 | 管理详情预览范围、显示阻止原因并确认删除；保留玩家、人物草稿及图片资产 |
| 实时消息 | 用户路由共用社群 SSE（服务器推送事件）连接，支持断线恢复、过期游标重读和访问撤销 |
| 内部失败诊断 | 用户页面显示操作提示，管理角色及玩家页面展示内部错误类型 |

图片上传、社群封面生成和聊天背景生成保留后端能力，当前没有前端入口。逐字输出与立绘差分没有接入需求。

## 尚待后续阶段

活动对象读取与动作提交在活动阶段接入，当前契约尚未提供活动端点。需要列出活动、读取权威状态和版本、读取玩家观察范围、列出合法动作、提交动作及读取结果；完整设计见 [活动接入设计](../../server/docs/design/activity-integration.md)。

管理鉴权、玩家账户和模型配置界面仍按现有项目范围处理。当前主体来源集中在身份模块，界面不请求模型提供方。
