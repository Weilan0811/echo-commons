# 任务 8：记忆与已实现反思适配

状态：已完成。完成日期：2026-10-02。实施范围见 [任务 8](03-backend-implementation-plan.md#10-任务-8记忆与已实现反思适配)。本阶段以独立英文 Git 提交保存，可通过 `git log --oneline` 和 `git show` 查看完整修改。

## 实际结果

同一会话按角色保存独立记忆段，来源关联包含精确可见消息及当前角色自己的 Thought（内心记录）。公开消息可以进入多个角色的段，私有消息只进入具有观察资格的角色材料。首尾序号表示范围，实际来源以保存的标识和版本为准。

三种图 `segment_reflect`、`continuity_compress`、`memory_organize` 已接入真实角色实例、模型、节点审核、图级审核和事务提交。反思领域对象、契约、材料组装与存储归 `modules/reflection/`；记忆归段、摘要、整理、索引和来源消费归 `modules/memory/`；内部状态和关系事实由 `modules/characters/` 写入。

## 模块和输入边界

- `InvocationInput` 定义共同调用范围、来源版本和工具读取规则；对话与反思保留各自的具体输入。通用执行器通过明确的输入转换接口组装模型消息。
- `CharacterContext` 统一组装模板身份、实例内部状态和自身关系认识。`WorldReader` 明确声明公开名称与完整观察接口。
- `GraphContext` 组装共同的角色、记忆、环境和工具输入；`SegmentContext` 选择消息与自身 Thought；`SummaryContext` 选择实际摘要批次及连续摘要的前一摘要。
- `ReflectionSources` 在模型执行前、模型并发预算等待后、每次供应商重试前，以及提交时检查来源。清除的 Thought 文本不能继续作为模型材料。
- `MemoryBootstrap` 在实例创建事务中保存预载记忆并建立正式索引。检索工具的参数说明、默认数量和实际上限使用同一配置。

各任务快照完整保存具体类型和来源版本。模型调用期间不持有数据库写事务。

## 记忆与业务事实

归段按配置中的消息数量、材料数量和文本预算选择完整消息及其自身 Thought，剩余来源由后续归段处理。并发或重复归段不会重复关联同一角色的来源，离开后重新加入继续遵守历史成员区间。

`SummaryBatches` 选择连续且实际可用的段摘要。连续摘要保存准确覆盖序号和前一摘要引用，过时结果不能覆盖已经推进的摘要链。摘要内容版本从 `1` 开始，同一批次不能保存不同摘要。

记忆整理通过明确写入对象保存长期记忆、实体、别名和关系；模型局部实体标识转换为当前角色私有的正式标识。同一角色的规范别名唯一并复用原实体。整理消费和检索投影在同一事务内保存，明确无操作的整理结果也记录来源消费。

关系候选保留实际 `ActorRef` 目标，按目标和维度去重。允许目标从消息发送者和明确提及主体中提取，排除当前角色自身；提示词与审核共用该规则。既有关系数值算法及 `interaction` 证据行为保留。内部状态按种类递增版本，活动自述沿用 24 小时有效期。

`ReflectionFacts` 将图候选转换为所属模块的写入对象；`ReflectionGraphCommit` 保存审核、聚合产物、图终态和业务事实。业务校验失败撤销事实写入并保留审核决定；数据库异常撤销整个事务。

## 调度、恢复与诊断

`ReflectionWorkflow` 提供明确的段反思与摘要消费调度入口。相同角色、图种类和来源复用原图及冻结输入。已有自动触发缺口保持原状。

`ReflectionHandler` 接入正式任务注册表和后台执行循环，与对话共用模型并发预算。反思执行期限为独立配置的 300 秒，使用共同心跳；强模型的单次请求期限为 120 秒。供应商默认思考策略保留。

启动和后台循环恢复过期节点租约。执行次数与租约代次限制迟到提交；角色不可用或社群暂停后不继续续期。必要节点失败结束图；可选节点失败仍准备后续聚合输入，并由原领域规则形成 `partial`（部分结果）。

`ReflectionRunView` 按社群和角色读取图、快照版本、节点、产物、模型使用记录、审核决定、业务事实和追踪投递状态。已清除的 Thought 在诊断快照中返回空内容及清除时间。不同图即使引用同一批次，其事实也按图种类读取。
