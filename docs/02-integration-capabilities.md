# 前后端能力接入

## 记忆初始化预算

普通反思沿用 `reflection.max_candidates` 与 `reflection.max_output_chars`。作者初始化按材料规模计算，每份材料默认允许八项候选，正文预算为材料字符数的六倍加 8000；两个值至少达到普通反思预算，分别不超过 `initialization_max_candidates`（默认 256）和 `initialization_max_output_chars`（默认 160000）。这四项初始化参数可以在 reflection 配置中调整。

长期整理的记忆页节点获得三分之一候选额度，实体关系节点获得其余额度；两个节点各获得一半正文额度。执行提示与节点审核共用计算规则。材料超过输入批次容量时继续分批处理，全部整理成功后再准备核心记忆。

正文预算统计候选业务字段，来源引用单独校验，不能引用输入范围外材料。最终提案按来源组保存，同一组引用只保存一次；读取时恢复候选的来源引用。已有逐项保存引用的提案继续可读。管理审核产物记录实际数量、正文长度及限制。

作者初始化因最终预算审核失败而重试时，新审核保留历史决定，并复用已完成的独立模型节点产物；来源仍须有效。模型调用失败继续按已有恢复规则执行。

## 接入范围

角色插画生成、头像裁剪与资产选择纳入本轮；图片上传、社群封面生成、聊天背景生成不提供前端入口。官方封面选择继续保存到社群。用户页面只展示操作提示；内部失败类型与任务诊断留在管理端。

公开角色、人物候选和生图任务响应不包含内部失败字段。管理角色响应保留记忆错误及准备阶段。记忆索引状态与失败项均有正式响应类型，前端类型通过 OpenAPI 生成。接口请求支持 PATCH 和文件表单，普通业务错误继续供客户端处理冲突与重试，用户页面不展示内部错误文字或编号。

## 社群管理

用户社群页提供当前社群启动、暂停和官方封面选择，写入时使用当前状态版本。新社群默认暂停，创建表单可选择官方封面。社群卡片与聊天头部读取保存的封面引用，空引用使用渐变。

管理列表按游标加载，每页 20 个，显示已加载数量；`q` 在服务端按名称或编号进行子串查询，查询范围绑定分页游标。管理社群详情提供暂停、清理范围预览和确认删除。预览展示数量、阻止对象及保留资源，执行再次检查范围，失败重新读取预览。成功后清除被删除社群缓存及本地当前社群选择。

## 角色插画

草稿「初识」章节在暂存后提供生成与插画库入口。生成使用草稿编号、修订号及外观补充；插画完成后由作者选择方形头像范围，服务端裁剪并保存资产。头像资产编号写入草稿，定格时成为模板默认外观。人物档案可更换当前实例的插画与头像，写入携带外观版本，恢复默认时清除实例覆盖。该操作保留人物设定与其他实例外观。

使用 `react-easy-crop` 处理拖动、缩放和裁剪区域，服务端校验并生成实际头像。图片地址 `/api/` 由统一客户端解析为后端地址。生成任务编号保存在本地，关闭面板或刷新后继续读取进度；提交结果未知时复用生成请求编号，外观保存失败后复用已经裁剪的头像。插画库按游标读取。用户页面显示友好操作提示。
