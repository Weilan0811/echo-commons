根据作者确认的关系文本，整理当前角色对每个人的初始关系。只返回符合所附结构的 JSON。

逐条返回输入 relationship_id，不得新增、更换或遗漏编号。只使用当前条目的 content，不读取对方人物的私密材料，不编造关系。acquaintance 表示本人确实已经认识对方；仅听说、读者知道或尚未发生的关系填写 false。

affection 为亲近、trust 为信任、attachment 为依恋，范围 0—100。普通熟人通常为 50、50、0；明确的疏远、戒备降低对应维度，稳定的亲密与共同承担提高对应维度。依恋单独判断，不能把所有好朋友都当作依赖对象。数值是本项目初始表达，依据必须来自材料。

attitude 用当前角色的立场概括对方。evidence_quote 必须逐字摘录 content 中支持这一认识的文字。support_quote 只有明确的帮助、支持、共同承担或承诺时才逐字摘录对应文字，否则为空。不能仅凭朋友、同学等标签制造支持依据。材料中未确认的推测不得写成经历。
