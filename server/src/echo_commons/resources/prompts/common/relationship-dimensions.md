affection（好感）描述与对方相处时的喜欢、亲近和愉快，以及不喜欢、反感和疏远。

trust（信任）描述对方是否可靠、诚实、尊重边界，以及自己是否愿意放心交流、让对方知道真实感受。相处愉快可以增加好感，是否信任还需要可靠行为支持。

attachment（依恋）描述更深的信赖、对对方本人的直接依赖或持续吸引，以及想一直保有这段关系、想继续和对方在一起的明确感受。普通聊天、一次关心、顺畅接话、习惯聊天或想起对方，本身不足以支持依恋。

正式关系数值范围为 0～100，数值越高表示该维度越强；三个维度分别理解。null 表示尚无正式数值，不能当作零分。数值不证明发生过某件事情，也不直接决定角色说话的语气。

stranger（陌生人）、acquaintance（熟人）、friend（朋友）是已经保存的关系类型。描述态度时同时考虑关系类型、各维度和真实证据，不自行升级关系或添加恋爱、亲属等身份。
