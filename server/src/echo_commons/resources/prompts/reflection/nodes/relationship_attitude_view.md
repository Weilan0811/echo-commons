用角色第一人称留下一小段对当前这个人的认识。正式关系和 evidence 说明你们已有怎样的相处；人物档案与 voice 帮助你用自己的方式表达。

选择当前目标已有的有效事实和角色认知，用自然称呼表达目前的认识。事实保留陈述归属，认知表达角色已经形成的理解；本节点不新增另一套长期判断。已有认识仍成立就保留，已有认知发生合法变化时更新对应部分。

当前对象由材料中的 target_name 称呼明确指定。段摘要可能同时提到几个人，逐句认清是谁做了什么；target_messages 提供当前对象在这段来源中的实际发言。其他人的话与经历不能移到当前对象身上。输出前再核对正文里的称呼与 target_name 是否一致。

首次描述已有实际互动、尚无长期认知时，概述已经发生的交流和目前了解的内容即可。保留实际熟悉程度，自己愿意继续交流不能证明对方喜欢、信任或依赖自己，不补写隐藏动机或稳定性格。

affection、trust、attachment 和关系类型只是理解背景。正文用实际认识表达，不写分数、维度标签，也不建议修改数值。顺畅交流可以留下不错的印象，深度信任和依恋仍需要相应依据。

口吻沿用人物的实际表达。可以直接进入印象，也可以提到相关事情，不要求每段都以“我觉得”开头，再以“保持边界”结束。确实存在的复杂心情可以保留，尚不确定的判断只在相关处说明。没有独立信息的礼貌铺垫、逐句免责和性格分析不进入正文。

互动事实、自己的感受和对方的说法各按原有性质表达。没有依据时，不补写对方原话、隐藏动机、未来承诺或共同过去。有证据记录但正文未提供时，只按正式关系和可读取内容表达有限认识，不猜测遗漏的具体事件。

证据正文没有提供时，只能确认这段关系已经建立，不能确定那次互动留下了怎样的印象。描述当前熟悉程度即可。材料不可读取不表示角色忘记了经历，也不能凭基准分数补写“印象不错”“没有恶意”等判断。

定稿前检查目标是否明确、印象是否有依据、熟悉程度是否准确，以及描述是否变成今后每次说话都要执行的规则。保留事实和真实态度，文字简短、连贯即可。

content 通常 80—180 字符，最多 $relationship_attitude_max_chars 字符；信息很少时可以更短，不为凑字数添加故事。

initial_description=true 且提供有效关系证据时，生成有限的初步描述。initial_description=false 时，保留仍成立的认识，更新确实变化的部分；本次没有新认识且已有描述仍成立时，返回空 content 和空 sources，表示保留原描述。

目标仍为陌生人或正式关系没有有效证据时，返回空 content 和空 sources。材料读取失败由运行编排层处理，不能解释为证据不存在。

只返回 content 和 sources 两个字段。content 是对当前对象的关系描述，sources 填写实际支持正文的材料编号数组。目标身份由程序处理，正文保留自然称呼。没有需要改写的内容时返回 {"content":"","sources":[]}。
