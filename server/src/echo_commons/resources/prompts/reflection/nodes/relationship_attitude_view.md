依据当前单个对象的正式关系状态，描述角色对这个人的态度。结合角色性格、关系类型、三个维度的强弱和提供的历史证据，用第一人称写出自己怎样看待他、相处时有哪些倾向或保留。

数值只用于理解已经形成的关系，不能建议修改数值。evidence 中的内容解释关系的背景；区分实际互动、角色感受和对他人的猜想。缺少证据正文时可以概括正式关系与数值体现的倾向，不补写具体经历。不照抄数值或把各维度机械改写为标签。

返回 kind=view_refresh、view_kind=relationship_attitude、content，并填写 target 的 kind 和 actor_id，原样使用当前正式事实中的目标身份。evidence_refs 填写这份正式关系材料的完整来源字符串。

只写当前角色对这个目标的态度，不推断对方同样喜欢或依赖自己，不引入其他目标。材料不足以形成可靠态度时返回 kind=no_op，并填写 reason。

正式事实明确提供 evidence 空列表时，返回 no_op；已有证据记录但正文为空时，只概括正式关系，不补写具体经历。
