# 原始记录、上下文摘要与长期事实及认知

状态：已接受。

## 决定

消息保存实际发言，自身 Thought 保存当时的主观原文。段摘要和连续摘要压缩交流上下文，保持人物和话题连续性。长期记忆使用独立的 MemoryFact 与 MemoryCognition，分别保存有来源性质的信息和角色有依据的认识。

长期整理根据段定位并读取原始材料，依次提取事实、代码审核、形成认知、聚合提交。事实合法完成后，即使认知失败也可以保留正式事实和处理进度，恢复只完成认知。核心与关系视图选择并表达已有记录。

对象、来源、存储和读取由 [记忆设计](../design/memory.md) 定义，操作与恢复由 [长期整理](../design/reflection/memory-organize.md) 定义。

## 原因

摘要需要压缩，原文中的细节可能被省略。长期整理取回原文，可以保留摘要没有写出的重要信息。单个长期记录围绕一项信息组织，可以引用不同段的来源，也能按具体事项更新。

原始发言、角色感受和后来形成的判断具有不同证据性质。分开保存事实与认知，才能在新说法出现时保留旧陈述，同时更新角色看法；重复摘要不会自动加强推断。

实体邻接不足以证明记忆之间有实际可用联系，长期记录的来源与支持关系用于核查依据。读取使用普通检索和明确引用，不建立实体别名、邻居扩展或通用关系边。

## 维护影响

原始来源、摘要覆盖、事实处理和认知处理各自登记进度。事实纠正与认知修订使用各自操作和版本，认知支持实际事实版本。源材料失效时复核依赖认识，历史记录仍可查。

状态和关系数值继续由角色模块维护，长期整理不重复计算影响值。核心与态度表达不再形成另一套长期认识更新规则。重建先备份并核查来源，不保留旧混合页的运行时转换。

实现差异与验收维护在 [状态](../status.md)，单元顺序见 [04 号方案](../../../docs/archive/implementation/04-experience-and-character-quality-plan.md)。
