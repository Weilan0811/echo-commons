# 共同观察资格

状态：生效。基线版本：`0.1.0`。

## 决定

客观世界通过 perspective 按社群、观察者、消息上限和成员区间读取。消息查询、任务输入、检索和反思复用同一可见性规则。

## 实际影响

索引只提供候选，正式读取仍校验来源资格。主观状态、关系和长期记忆分别由所属模块提供。

实现依赖见 [系统设计](../design/system.md)，字段约束见 [数据库](../reference/database-schema.md)。当前差异与审核状态见 [状态说明](../status.md)。

## 背景与成立条件

公开历史、角色输入、搜索、归段与反思都读取消息。若各自定义成员和受众规则，私有消息可能通过索引或摘要进入其他角色输入。

perspective 复用正式成员区间与消息受众，观察上限表达本次历史位置。message.sequence 位于区间内仍不足以证明可见，需要同时验证实际受众。重新加入获得新区间，不能替换旧任务和旧受众中的区间身份。

## 维护影响

客观观察只读所属模块事实；自身状态、关系认识和长期记忆分别由 characters 与 memory 提供。新增活动使用实际读取适配，沿用角色范围与具体玩法可见规则。检索重建必须通过同样的来源资格，索引不能独立授予读取权限。

## 会话发送范围说明

新玩家发送统一采用会话范围，部分成员交流通过独立会话完成。消息仍保存实际成员区间，读取继续复用本决策的规则，以保持离开、重新加入、冻结轮次回应和历史私有记录的正确范围。历史记录不会因当前成员变化而获得新的接收主体。
