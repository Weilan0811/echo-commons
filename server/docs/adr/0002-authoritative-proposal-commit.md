# 行动提议与权威事实

状态：生效。基线版本：`0.1.0`。

## 决定

Agent 只根据明确输入提出行动。业务审核检查范围、来源、当前租约和正式规则，提交入口原子保存结果及事实。

## 实际影响

同一输出可以被规则拒绝，成功运行状态不自动成为业务事实。重复提交依靠实际业务唯一约束和正式查询返回原结果。

实现依赖见 [系统设计](../design/system.md)，字段约束见 [数据库](../reference/database-schema.md)。当前差异与审核状态见 [状态说明](../status.md)。

## 背景与成立条件

模型输出存在格式错误、来源误用与迟到结果。一次生成成功只能证明候选已经产生，任务执行期间角色成员、社群状态和租约也可能发生变化。

因此模型及工具不能直接修改数据库。业务审核检查输出契约、具体来源、角色范围与当前资格，正式提交将事实和完成记录放在同一事务。旧代次与过期受众均需重新检查。

## 维护影响

对话、反思和未来活动有各自审核及提交规则，共用执行协议。工具保持明确只读权限；增加可执行行动时须建立所属业务的正式入口和验收。结果、消息、Thought 与反思事实的重复提交分别由实际身份和来源消费检查处理。
