# 人物模板与独立实例

状态：生效。基线版本：`0.1.0`。

## 决定

人物模板是作者定义的版本化资源。每个角色实例有自己的社群归属、状态、关系、记忆和任务，初始化复制正式初始材料。

## 实际影响

同一人物可以出现在多个社群或同一社群的多个实例中；模板升级需要明确实例采用规则。

实现依赖见 [系统设计](../design/system.md)，字段约束见 [数据库](../reference/database-schema.md)。当前差异与审核状态见 [状态说明](../status.md)。

## 背景与成立条件

同一人物内容需要在多个社群或同一社群多次实例化。作者档案、语气、关系倾向和初始记忆可复用，每个角色后续经历、状态和关系认识分别变化。

BlueprintCatalog 负责预置文件加载与格式校验；BlueprintReader 提供文件预置和 SQLite 自定义人物的共同版本读取入口。CharacterBootstrap 负责正式实例及初始私有数据。任务记录实际模板版本与角色身份，跨模块读取继续检查社群与实例范围。

## 维护影响

新增模板不要求增加业务分支；角色初始化不依赖固定人物或默认社群。自定义人物经草稿确认保存为固定版本，生成候选与确认分别执行。确认后不可编辑，复制产生新草稿；已有实例重置待专项设计。具体规则见 [自定义人物设计](../design/custom-character-authoring.md)。原任务快照保留实际准备时的人物内容。
