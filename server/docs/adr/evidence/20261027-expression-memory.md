# 角色表达与记忆整理的实验依据

记录日期：2026-10-27。关联决策：[角色表达与按需检索](../0013-character-expression-and-retrieval.md)、[社群世界设定](../0014-community-world-context.md)、[独立整理诊断](../0012-memory-draft-diagnosis.md)。

最终选择是在一次生成中完成必要的私有核查与公开表达，缺少相关旧事依据时调用记忆检索；提示明确各动作职责，删除重复说明与重复事实主题。记忆整理保留任务专属上下文，撤去未显示稳定收益的额外准则。下文分别交代实验数据、解释和采用理由。

## 1. 怎样评价

**表达质量。**角色可以补充未设定的个人日常、感受和未来安排。涉及他人的行动、原话、共同旧事与已有责任时，需要本次实际提供的人设、关系、聊天或记忆支持。确认整件事发生后再说忘记细节，仍可能属于编造。暂时不记得整件事与承认事情发生分别评价。

**行动质量。**需要查找旧事时是否实际检索、已有依据时是否重复查询，独立记录。安全否认可以通过事实检查，同时没有遵守先查询的要求。一个目标记忆编号没有召回，也不能证明整个输入缺少相关依据。

**整理质量。**按给定材料检查主体、时间、否定、条件、说话者、计划及完成状态。允许正常压缩、人物理解和核心记忆取舍。给定正式认知已经包含的说法，后续节点继续保留时，不算该节点新增编造。引用编号存在且有资格，与引用文字确实支持正文分别检查。

**完整可用回应。**回复有用、主要任务完成、没有明确无依据共同事实，也没有公开代码、协议或幕后说明。空白、解析失败、截断和未完成回答分别记录，失败后不重新抽取来提高分数。

各轮题目、模型和评价范围不同，以下比例只在所属对照内比较。质量由执行实验的助手复核，未完成用户独立盲评。重复来自固定材料，不能当作同等数量的独立真实用户场景。

## 2. 仅修改边界、示例与来源说明

实验标识：`participation-factuality-20261022/b-study`。固定远程DeepSeek、关闭思考。每个条件的正式表达共96份，其中48份属于无依据或有反证的压力输入，24份属于已有支持材料的输入，其余用于其他表达观察。下表采用扩展后的人工复评，包含接受玩家假前提和另外编出替代事实。

|提示内容|出现无依据事实／48|有依据却认不出／24|平均输入token|
|---|---:|---:|---:|
|原有规则|22|1|3631.75|
|统一事实边界|17|1|3585.75|
|统一边界加短示例|15|2|3724.75|
|统一边界加来源说明|13|0|3671.25|
|边界、示例和来源说明全部加入|16|0|3810.25|

来源说明在该批材料中错误最少，相比原规则少9次；完整组合没有进一步改善。三种条件另各运行6段三轮对话，18段均未完整保持事实边界。错误会经过摘要与认知保存后再次被使用。来源说明条件没有运行这项连续验证，不能把它的单次优势扩展到连续对话。

**采用理由：**保留来源与事实边界作为基础要求；停止通过不断堆叠示例和同义禁止句解决问题。主要成本变化较小，可靠性比提示长度差异更影响此处选择。

## 3. 整理职责、材料预算与独立诊断

实验标识：`expression-memory-20261023`初次消融，以及其下`bottleneck-study`。

|检查内容|同条件结果|能够支持的决定|
|---|---|---|
|整理任务分离|五类节点各两次；平均输入从4338.0降到3983.4token，减少约8.2%|整理不再带聊天即兴指令，职责分离和输入减少均可确认|
|相关事实保留|相同6751字符预算，原算法保留0条，新算法4条；两组各3次回应，均有1次改变早餐经历|保留输入完整性修正，尚不能宣称表达质量提升|
|事实候选诊断|两份固定草稿，每稿平均额外3次请求、11.3秒；限定修改后1份通过|诊断代价明显，通过不等于语义正确|
|摘要与认知诊断|八份固定草稿，每稿平均额外2.25次请求、约5秒；限定修改后6份通过|诊断可选，默认关闭|
|模型与思考深度|独立表达验收，现有DeepSeek与MiniMax高思考各7/24份出现公开事实问题|没有足够依据改变默认模型或常开深思考|

诊断确实修正过场景拼接和“实际失控”被改成“差点失控”，也会把两次救援混为一次、要求补全正常省略，推动写作者误改。高思考诊断的20份开发结果中有3份耗尽8192输出额度。

**采用理由：**继续保留任务分离、相关事实优先和既有可选诊断。诊断的默认关闭已经避开其常规调用成本，当前没有删除其全部实现的证据或需求。

## 4. 为什么让核查参与同一次表达

实验标识：`shared-facts-20261024`、`judgment-expression-20261024`、`premise-retrieval-20261025`。

共同事实实验中，八个相机配对条件的独立判断全部指出缺少借用依据，八份自然回复却全部接受借用。直接表达前已经识别出问题，仍不足以约束公开发言。

随后固定相同材料比较表达方式：

|方法|结构有效／20|有效压力回复中接受假旧事|每份生成次数|中位耗时|全未缓存参考费用，元／千份|
|---|---:|---:|---:|---:|---:|
|给出待核查主题，直接表达|20|1/12|1|1.25秒|3.985|
|人工提供正确依据判断，再表达|20|0/12|1，另有人工作业|1.27秒|4.042|
|同次核查与表达，字段说明不足|15|0/9|1|1.50秒|3.923|
|分开生成核查与表达|19|0/11|2|1.93秒|7.622|
|同次核查与表达，明确字段结构|20|0/12|1|1.46秒|4.211|

结构失败没有计作成功拒绝。人工判断一组只用于定位问题，不能作为自动系统的运行成本。补充主题说明实验中，同一批压力问题的接受次数从6/12降到0/12，说明具体前提如何进入输入也有影响。

自动前提实验进一步发现，显式核查覆盖8/8条关键前提，只列前提覆盖5/8；两者在7份有效压力回复中都未接受目标假旧事。人工列出的前提若没有附带依据判断，仍有5/7被接受；加上核查后为0/7。列举某件事本身可能被误读为确认。

**采用理由：**核查和表达在一次生成内完成；字段结构明确；不增加固定的独立前提提取或审核调用。核查是否有依据与来源身份是否有效分别验收。

## 5. 为什么允许按需检索

实验标识：`final-agent-acceptance-20261025`。三个方法共用事实准则、世界背景、人物资料和真实记忆工具；每组27份单次回应。

|指标|直接表达|固定核查后表达|自主选择核查和检索|
|---|---:|---:|---:|
|明确共同事实错误／27|6|2|1|
|初始确实缺少依据后找回／7|2|2|6|
|普通交流没有核查条目或查询／4|4|3|3|
|原24题实际生成次数|27|24|34|
|原24题实际检索次数|3|0|11|
|原24题每次回应中位耗时|1.52秒|1.63秒|1.90秒|
|原24题全未缓存参考费用，元／千份|5.38|5.42|8.39|

真正初始遗漏的7次机会涉及5件旧事，包含同一事件的直接问法和代词追问，只有5件不同旧事。早一轮真实检索题全部已经初始命中，未将它们算成遗漏找回证据。

六段三轮对话中，直接表达13/18份交付、其中3份有明确共同事实错误；自主方法18/18交付，主要口径未见明确共同事实错误。自主方法仍会新增更严格口径下的共同细节，也会在话题切换后继续搜索旧事。

**采用理由：**按需检索改善过遗漏找回，额外费用有具体收益。固定核查容易在判为未找到后直接结束。原24题自主方法成本比固定核查高约55%，其中生成次数从24到34，主要增长来自工具往返，不能全部归因于核查字段长度。

## 6. 表达提示精简的取舍

采用的提示同时明确私有核查、查询材料、公开表达三种职责，删除无用字段注释与重复旧事说明，仅去掉记忆展示中与事实正文重复的主题。保留正文、来源、字段约束和可空核查；允许直接消息或核查加消息两种结束形式。

实验标识：`prompt-replacement-qwen35-20261026`，本地修订复测与五组合、远程五组合分别记录。

本地五组合各完成72次回应。未精简的核查检索基准完整可用20/72，拟采用的精简提示15/72；其他组合最高22/72，也未通过预设成本和质量门槛。本地输出中存在事实问题、公开协议片段与长输出，证据不支持将本地角色模型作为已验证的默认替代。

远程DeepSeek先用六题比较全部六个条件，再选择两名候选完成六道其他题的两次重复，最后对其中一名候选进行连续对话。正式回应96次，另有2次预检，共121次模型请求。基准与拟采用精简提示的同阶段结果如下：

|阶段与每组回应数|方法|完整可用|事实或依据错误|无用回应|执行失败|实际生成／检索|全未缓存参考费用，美元|
|---|---|---:|---:|---:|---:|---|---:|
|初筛，各6次|未精简基准|5|1|0|0|8／2|0.006852|
|初筛，各6次|精简提示|6|0|0|0|8／2|0.006562|
|复验，各12次|未精简基准|8|2|2|0|13／1|0.010276|
|复验，各12次|精简提示|7|3|2|0|17／5|0.013505|
|连续对话，各12次|未精简基准|10|0|0|2|15／3|0.012973|
|连续对话，各12次|精简提示|10|0|0|2|15／3|0.012144|

复验中精简提示首次输入减少4.9%，实际检索从1次增到5次，全部输入增加31.7%，参考费用增加31.4%。新增查询主要出现在拒认虚构礼物、债务以及找回真实衣服图案。两组对礼物、债务均能拒认；精简提示多找回一次真实图案，同时在仓库题和现金题失分。因此，多出的查询同时包含契约执行改善、实际找回收益及没有改变公开正确性的成本。

连续对话两组质量相同、调用次数相同，精简提示参考费用低约6.4%。121次请求无长度耗尽，单次最大输出310token；共有4次空白和1次结构异常。两个模型实验的接口约束与采样参数不同，不能把差异全部解释成模型大小。

**采用理由：**这套精简提示没有通过原先的自动采用门槛。用户综合初筛、连续表现、模块适配、维护和工期明确选择采用，接受剩余质量风险。原门槛与失败结果保留，不追改为全面获胜。正式接入使用现有原生工具；远程组合实验的JSON动作适配需要通过集成验收，不能直接冒充正式路径已验证。

## 7. 为什么撤去额外记忆整理准则

实验标识：`memory-calibration-quality-20261027`。两组都保留任务专属上下文、相同人物与材料、日富美单示例、字段结构和来源编号，只改变共同规则及节点说明。

五类节点各两份已有输入，每组重复三次，共60次真实DeepSeek请求；temperature=0.7、top_p=1、非思考、最多4096输出token，无工具、无诊断、无重试。材料有主题和人物重叠，未当作全新独立测试集。先冻结核对点，生成结束后混排审阅；执行者可以访问映射，不声称独立盲评。

|指标|任务分离后的原整理提示|增加额外整理准则|
|---|---:|---:|
|实际结果数|30|30|
|结构与来源绑定通过|30|30|
|明确含义或主体改变|1|1|
|所引材料不足以支持正文|1|1|
|未确认内容变成确定表述|1|2|
|上述三类至少出现一项|3|4|
|重点内容遗漏|0|2|
|复杂作者事实提取残留百科标签／3|3|3|
|全部输入token|131715|138405|
|全部输出token|10831|10223|
|全未缓存静态参考费用，美元|0.026256|0.026895|
|回应中位耗时|1.72秒|1.77秒|

问题类别可以重叠。明确含义错误与引用语义不足合计各组均为2/30份；加入确定程度问题后为3/30与4/30。额外准则组两次遗漏同一份复杂材料中的较早营救事件，不能解释为两种独立事件都退化。普通早餐与未履行的邀约两组均能保留，核心记忆与认知均能保持人物语气。

额外准则输入增加5.1%、输出减少5.6%、参考费用增加2.4%。实际缓存更热使该组缓存估费较低，选型仍按全未缓存口径比较。共同规则与五类节点说明一起变化，本轮不能独立归因到某一句要求。

**采用理由：**没有测得跨材料的稳定质量收益，额外文字又增加输入与维护负担，因此恢复经过测试的任务分离后原提示。它已经要求说话者、否定、条件、计划和来源资格。此决定不宣称小样本证明原提示总体显著更好，也不撤销任务分离、示例、事实输入优先与诊断能力。

## 8. 匿名化案例与错误位置

以下只替换姓名或物品称呼，保留实际问题结构与判断。用于说明错误位置，未生成新的实验样本。

**混合前提。**正式记忆为“只带回证据”。玩家问“取出来还债的现金交给乙了吗”，精简提示的回复为“取出来的现金……我记不太清后来交给谁了”。核查检查了交付，却接受了取款前提。未精简基准也有一次明确确认现金交接，两组共享这个缺口。

**检索选择。**真实记忆保存了某件衣服的图案。精简提示在完全相同的初始输入下，一次查询后答对，一次不查询就表示不记得。已有数据能找到与角色是否选择查询分开验收。

**材料未进入输入。**仓库记忆在数据库中写明睡得不舒服，当次初始输入没有这条记忆。回复未查询，却说垫子好睡；另一份补出同伴陪了半天。错误发生在未恢复依据后补写经历，不能描述成已看到正确记忆仍忽略。

**主体与否定。**增加准则的认知结果把“甲记得乙阻止过自己”写成“乙还记得阻止过甲”。原提示的另一份结果给同伴的正面原话增加了否定。额外准则没有消除这两类改写错误。

**引用语义。**两组各一份事实结果把只读人物背景的年级和职位写入候选，引用的作者材料却没有这些内容。身份没有凭空编造，引用仍然不足；编号合法无法发现这个问题。

**上游污染。**输入正式认知已有“明天别再让对方等我”，后续核心记忆继续使用。原始聊天没有等待记录的风险属于上游，本次没有要求下游推翻给定认知。

## 9. 证据范围与后续验收

费用均为各轮按记录单价计算的参考值，未读取账户账单。人民币与美元、缓存与未缓存、不同阶段题目之间不直接比较。远程请求别名与返回名分别保存，没有独立验证服务权重版本。

世界背景在具体世界知识题上有帮助，未证明可修复个人共同旧事；将其作为用户维护的常驻背景，依据还包括产品语义和现有社群职责。没有把世界背景收益与核查收益混为一项。

正式验收仍需覆盖原生工具往返、私有核查权限、来源、完整输入预算、任务恢复，以及先否认后找回更正再写入记忆的流程。最后一项尚无完整质量通过证据。任何为时间归属增加的新提示都应单独标记并验收，不能计入已经比较过的原整理提示结果。
