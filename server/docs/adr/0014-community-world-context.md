# 社群维护世界观与交流规则

日期：2026-10-27。状态：采用，待实施。依据见[实验摘要](evidence/20261027-expression-memory.md)。

## 问题

角色资料与个人记忆没有明确说明社群所处世界和交流方式。实验中，明确世界背景帮助回答具体世界事实，但没有单独解决共同往事编造。

## 决定

在现有社群模块维护世界观正文与社群规则正文两个文本字段，由用户通过社群业务入口修改。世界观说明世界本身的基本事实；规则说明这个社群的存在与交流方式。游戏状态、动作和权威结果继续由Activity及游戏模块提供。

读取时将两份文本与版本纳入冻结上下文，作为与角色核心记忆并列的常驻背景；需要这些背景的任务使用同一读取来源。角色反思不改写社群设定，角色不得通过生成文本改变其权威状态。

复用现有社群服务、接口和状态版本，不新增世界管理服务。数据库新增迁移，已有社群默认空正文，不自动填充特定作品设定。前端编辑界面单独安排。已冻结任务保留原输入，新任务读取更新后的设定。

## 影响与验收

固定背景增加输入长度，需要计入预算。内容由用户负责，系统提供可靠保存和注入；背景不是个人共同经历的证据。验收新旧社群、用户修改、版本与快照恢复，以及反思任务无法改写设定。
