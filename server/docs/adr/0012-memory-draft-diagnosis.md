# 角色记忆遵循与独立整理诊断

更新日期：2026-10-27。状态：职责分离与可选诊断已实现，整理提示已回退。运行细则见[整理草稿诊断](../design/reflection/execution-model.md#7-整理草稿诊断)，质量依据见[实验摘要](evidence/20261027-expression-memory.md)。

## 背景

角色需要补充普通个人生活，并在后续交流中保持经历一致。共同往事、他人的行动及游戏结果需要保留依据。整理时丢失说话者、条件或不确定程度，会使后续表达把一个说法当作亲历。

角色遵循记忆与整理准确保存内容各有职责。现有事实操作审核负责新增、支持和纠正旧记录，正文与材料是否一致需要单独检查。

## 决定

聊天使用人物共同契约与表达规则，整理节点使用所属任务规则和必要人物背景。普通个人补充按相关性保存，相关正式事实优先进入有限对话上下文。

反思模块提供独立草稿诊断。诊断只返回问题与依据，原写作者修改完整草稿，运行层控制复查、次数上限和恢复。诊断通过后，候选继续经过既有操作审核与业务提交。现有节点依赖保持不变。

事实诊断、摘要与认知诊断分别配置，默认关闭。诊断模型通过现有登记选择。数据库保存实际步骤，故障恢复复用已经完成的写作与检查，未通过产物不能保存为正式记忆。

## 影响

诊断增加模型调用、延迟和误报机会，测试需要同时评价修正收益与额外成本。真实对照表明，提示和相关记忆输入仍不能保证模型始终遵循事实，诊断也可能因误报达到修改上限。默认配置保留正常整理流程，开启诊断后接受其额外成本和停止条件。

角色无需判断提供给自己的记忆是否真实。记忆的来源、权限和版本继续由原有业务规则维护，结构审核和语义诊断分别验收。

## 整理提示采用决定（2026-10-27）

固定任务分离后，对照校准前共同规则及节点说明与当前额外准则，各生成30份。两组明确含义变化和引用语义不足次数相同，额外准则组另有确定程度变化与重点遗漏，未获得跨材料稳定收益。结构与来源绑定均通过，不能据此认定内容正确。具体错误、样本安排及成本见[实验依据第7节](evidence/20261027-expression-memory.md#7-为什么撤去额外记忆整理准则)。

共同规则与事实提取、片段摘要、连续摘要、认知、核心记忆五类节点说明已经恢复为测试过的校准前文字，保留当前任务分离。此选择降低没有显示收益的提示增量，不宣称原提示总体能力显著更优。原提示已经要求保留说话者、否定、条件、计划和材料资格；任务分离、人物单示例、相关事实输入和诊断能力继续保留。
