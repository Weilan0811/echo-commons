# 游戏经历与记忆整理

Activity 提供游戏经历的正式来源，memory 保存参与范围、引用和处理进度，reflection 安排已有的摘要与长期整理任务。游戏规则和逐步行动记录继续由游戏包维护。

## 经历范围与关闭

一段游戏经历属于一个社群、角色、游戏和 `participation_id`（实际参与编号）。离开后重新加入会形成另一段经历；两段分别读取原成员区间内可见的消息和游戏事件。

| 业务状态 | 经历处理 |
|---|---|
| 游戏进行中 | 积累可见事件、局内消息和自身实际内心；材料达到容量或空闲条件时整理阶段摘要 |
| 游戏分出胜负 | 清除当前意图，继续接受赛后交流，经历保持开放 |
| `end_activity` 归档会话 | 以实际归档时间结束经历，包含此前成功保存的赛后消息 |
| 取消、离开或会话归档 | 按实际结束时间和原参与区间关闭该角色的经历 |
| 暂停或进程退出 | 保留业务状态与处理位置，恢复后继续 |

关闭时间来自现有业务记录。后台扫描即使晚于关闭，也按原时间读取；反思延迟不会扩大可知范围。

## 来源与材料段

`ActivityExperiences` 使用公开游戏服务读取角色可见事件、结果及参与范围。`ActivityPerspective` 复核来源、版本和时间。memory 的事件引用只保存正式身份、版本与序号，事件正文仍从游戏服务读取。

`MemoryExperiences` 将同一参与区间内的正式游戏事件、局内消息及独立活动 Thought（内心记录）按实际时间组成材料段。内心必须关联真实活动结果，属于本人；没有配套发言也能整理。自动行动没有内心时保留空缺。任务输入、玩法分析缓存和当前意图不作为经历来源。

普通操作按材料预算积累，不按行动次数调用反思。阶段归段沿用材料数量、字符容量、空闲和实际结束条件；当前聊天历史需要摘要时，也可以提前整理对应原文。没有新增来源时不重复生成材料段。

`segment_reflect` 复用原摘要节点。简单模式保存摘要；完整模式按实际材料判断状态和关系。游戏回忆保留参与者、结果、转折、精彩片段、有意义的交流和自身感受；重复操作可以省略，连续事件可以合成一个片段。

## 阶段摘要、整局摘要与长期整理

本局阶段摘要通过原 `continuity_compress` 任务累计压缩，只继承同一参与经历的前驱摘要。关闭后继续处理剩余事件、内心和赛后消息；原定范围全部归段、阶段摘要完成且累计覆盖完整后，将最后一份累计正文登记为整局摘要。关闭前已经完整覆盖且没有新增材料时直接复用已有正文。

整局汇总只消费摘要，不重复执行状态、关系反思。长期整理继续独立登记事实、认知和原始来源覆盖；阶段摘要进入整局摘要后，原材料的长期消费位置保持原值。失败恢复沿用原反思图和节点恢复入口。

`memory_activity_episodes` 保存参与边界、事件处理位置、材料完成状态及最终摘要引用；`memory_activity_event_refs` 保存角色已取得的正式事件引用。材料段和摘要批次通过 `activity_participation_id` 关联经历。迁移 35 保留旧记录并扩展相关来源约束。

## 判断输入与回忆

近期游戏卡片保存本人参与编号、本人席位，以及参与区间内各人物的稳定身份、显示名称和本人标记。正式结果按获胜席位对应实际参与者；同名人物各占一项记录。离开后重新加入分别使用各自参与编号和原区间，后来的入座不会进入先前经历。

反思输入以 `activity_sessions` 独立保存材料对应的游戏身份与结果背景，每段经历使用其材料截止时刻读取；连续摘要继承实际覆盖段的身份背景。原始事件正文和来源版本继续保留原值，旧反思任务恢复时仍能复核来源。游戏事件、人物原话及自身认识在提示中分别标明，人物与材料编号由程序维护。

活动判断复用[共同上下文预算](perspective-and-context.md#4-历史裁剪与自身思考)，计入模型容量、输出预留、输出结构、工具和本地判断请求。历史需要摘要时，原任务等待已有反思完成，人物精简和玩法分析结果继续复用；等待不消耗模型尝试次数。必要输入本身超过容量时明确失败。

新判断不携带固定的最近五次私有想法，需要延续的打算由进行中的本局意图承担。旧冻结输入保留原有材料和读取方式。事件批次、事件处理位置、当前视图及玩法分析保持原有判断机制。

普通会话按共同预算取得近期游戏状态、结果、阶段回忆和整局摘要。全文检索包含摘要及完整模式的事实、认知；原始逐步事件不建立日常搜索项。来源复核仍可通过正式事件引用读取原文。当前意图及完整行动分析不进入普通聊天或记忆整理。

管理详情保留参与关联、来源、摘要覆盖和独立消费记录。来源查看、检索、导出和社群清理继续使用所属模块的入口。
