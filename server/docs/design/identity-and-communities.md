# 身份、模板、社群与成员

## 1. 稳定身份与世界范围

Player 的 player_id 是真人身份，可以加入多个社群。Community 的 community_id 是数据和世界范围。CharacterInstance 的 character_id 是全局唯一角色实例，固定属于一个社群，绑定 blueprint_id 与 blueprint_version。

ActorRef 使用 kind 与 actor_id，当前 kind 为 player 或 character。它用于玩家与角色的发送者、参与者和关系目标，避免用 account_id 混合表达身份与归属。system 表达系统消息来源，其成员和关系资格不能套用玩家身份；当前来源支持差异、通用事件引用及意愿范围分别见 [差异裁定](../status.md)。

社群成员说明主体是否属于世界；会话成员说明主体何时参与一段交流。两层资格都必须检查。角色创建和玩家加入均通过正式服务，不在启动时创建默认世界。

## 2. 人物模板及资源

模板是作者定义的可复用内容。角色档案表达稳定身份，voice 表达说话方式，relational_dynamics 表达关系倾向，capabilities 表达允许能力，memory_preload 表达初始记忆。共享 agent_contract 表达角色代理共同规则。

每份资源有身份、schema_version、content_version、状态与来源。加载器校验当前格式、引用和内容。模板加载后保持不可变；实例绑定明确版本，本设计不支持运行中静默换版。作者格式及合法示例见 [人物资源](../reference/character-resources.md)。

玩家自定义人物通过 [创作服务](custom-character-authoring.md) 保存到 SQLite，确认后固定为明确版本。共同人物读取服务供展示、上下文、执行绑定和实例创建使用。私有自定义人物仅作者可实例化，作者需要是目标社群成员；创建后同社群成员可以正常交流。故事与采访属于作者材料，其保存与初始化反思分别管理。

## 3. 实例化事务

输入为社群、模板及可选实例标识。现有服务检查社群与模板存在，处理同标识重复创建，然后在同一事务保存实例、初始叙事状态、初始私有记忆和社群成员。

模板记忆中的 self/self 解析为新实例。引用其他玩家或角色时检查实际社群成员。记忆身份属于实例，保留作者资源及版本来源。同一模板的甲乙分别拥有副本，后续事实修改不影响模板或彼此。

实例创建的数据库事务失败时全部回滚。目标流程另外选择固定运行模式，并通过独立准备状态管理作者材料初始化；模型或索引失败保留实例和已完成材料，允许重试。准备完成前不能参与聊天或活动。模式、重复请求和准备规则集中见 [记忆设计](memory.md#2-初始化可见性与有效期)，当前代码尚未接入这些扩展。作者资源缺失和格式错误在加载阶段明确报告，不能产生默认人格替代。

## 4. 成员区间与历史

Membership 保存一次加入身份、主体、会话、加入序号边界和离开边界。离开结束该区间；重新加入创建新的 membership_id。消息受众记录发生时的实际区间。

观察判断消息是否处于某个真实区间及其受众。离开不抹除原经历，加入前及离开后消息默认不可见。原任务绑定的成员区间结束后，即使角色同名重新加入也不能继续提交原任务。玩家新区间不能替代旧受众。

Alice 先加入，阅读消息 1—5，离开后出现 6—8，重新加入后出现 9。她的实际经历来自原区间与新区间允许材料；6—8 不能仅因 player_id 相同进入历史。回应延迟到重新加入时，若原区间已结束，该回应不会转移给新区间。

## 5. 世界时间与运行时间

Community 保存 world_time_utc、timezone 和 state_version。世界时间表示故事发生时刻，UTC 保存统一时间，时区用于得到 game_day。game_day 是世界当地日期，用于 Thought 与未来日记。

租约、网络期限、退避与日志使用真实执行时间。世界暂停、故事时间推进和网络等待是不同操作，不能通过改变世界时钟控制租约。

社群状态为 active 或 paused。暂停阻止新模型任务继续取得执行资格，未完成对话挂起；恢复继续原任务和快照。会话另有 active/archived，归档取消相关未完成回应。技术故障记录在任务中，不产生人物 technical_error 状态。

新社群默认 paused，创建、读取、加入社群和打开网页均不自动唤起。社群成员通过 [公开状态接口](../reference/http-api.md) 明确修改状态，请求携带读取到的 state_version 作为 expected_version；版本过期返回 409 并重新读取。重复设置相同状态不增加版本，进程重启保留已保存状态。暂停社群排除在记忆准备、段反思、摘要整理、认识刷新及聊天任务领取之外。

暂停沿用现有执行机制：对话任务释放租约并挂起，反思任务在心跳或结果提交时延后；恢复复用原任务、冻结输入与已成功产物。进行中的模型请求可能已产生供应商用量，恢复时未完成步骤可能重新调用模型。

## 6. 读取与变化边界

公开实例读取提供实例标识、社群、模板绑定、可用状态及版本，模板列表提供展示名字。观察中的公共身份可含名字。角色情绪、关系认识和记忆只由限定范围的内部输入读取。公共身份不能授权读取私有认识。

社群公开读取包含可空 cover_kind 与 cover_ref，分别表达前端预设编号或后端资产编号；创建和封面修改复用社群成员资格，修改检查 state_version。实例头像覆盖使用独立展示版本，共同公共身份读取解析覆盖或固定默认头像。展示变化不修改人物正文、角色经历或消息受众，资产规则见 [图像资产](image-assets.md#5-业务引用与展示)。

人物的 available、offline、busy 等可用状态决定回应资格；physical、mood、activity 等叙事状态表达角色自身认识，详细规则见 [状态与关系](character-state-and-relationships.md)。

创建、重复、跨社群引用、独立记忆、成员重新加入和暂停恢复均需要正式存储验证。当前实现与缺失分别见 [状态](../status.md)，开发定位见 [源码导航](../reference/source-map.md)。
