# 群聊参与判断与角色接话

状态：未实现的设计草案。更新日期：2026-10-05。

## 当前与目标

当前程序按提及和最近发言等规则选择角色，同轮任务分别使用冻结输入，角色发言不会自动开启后续轮次。正式现状见 [会话设计](../design/conversation-and-social.md)。

已确认优先推进内容相关的参与判断和角色间接话，自定义角色优先于本项。目标是甲提交发言后，乙的新任务能够读取该发言，选择回应或沉默；玩家能够在过程中插话，话题能够结束。

## 建议与待决规则

程序检查成员、来源可见性、可用状态和预算。提及及明确回复作为参与依据；模型结合人设、话题、关系和当前状态判断是否愿意发言。模型评估范围与是否增加独立调用需要考虑成本及响应速度，尚未确定。

接话通过已提交消息创建新轮次和新输入，原任务继续使用原快照。需明确轮次来源合并、连续接话次数、总调用预算、重复触发、玩家新输入优先安排及终止规则。当前回应资格、成员区间和受众规则继续适用。

本项响应已经发生的交流；没有新消息时的主动发起由 [主动开口草案](04-proactivity-topics-events.md) 负责。两者可以复用执行设施，各自保留触发原因与停止规则。

## 验收方向

使用真实模型验证角色回应彼此具体内容、合法沉默、玩家插话、有限连续交流和自然结束；验证成员离开、重新加入、任务恢复及重复请求不扩大受众或重复触发。
