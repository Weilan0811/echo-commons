# 后端能力与实现状态

更新日期：2026-10-06；软件版本：`0.1.0`。

本文件记录后端当前能力、验证范围及后端待办。完整业务规则以 [设计目录](README.md) 为准，实际请求和响应以 [接口参考](reference/http-api.md) 为准。整体阶段和前后端协作安排见 [项目推进计划](../../docs/01-project-roadmap.md)。

## 1. 当前可使用的能力

| 能力 | 实际实现 | 使用边界 |
|---|---|---|
| 社群、玩家和角色 | 创建与持久化；人物模板创建独立实例；公开接口 | 同一模板的不同实例分别保存状态、关系和记忆；没有玩家账户认证 |
| 自定义人物创作 | 默认模板、基础引导、三阶段确认、四种 AI 辅助、10～15 题分批采访、三文档校准、固定版本及实例创建 | 确认后不可编辑，可以复制新草稿；作者材料仅保存原文，尚未生成初始记忆；没有已有实例重置入口 |
| 玩家读取与阅读位置 | 玩家和社群发现、自身会话概要、当前参与者、最新历史与单条消息、服务端已读和公共头像 | 公开范围按本地 player_id 检查；管理有独立完整列表，规则见 [玩家 API](design/player-api.md) |
| 私聊和群聊 | 创建会话、加入、离开、会话消息、提及及回复；部分成员交流使用独立会话 | 读取按成员区间和实际受众过滤；重新加入不能获得离开期间的消息 |
| 连续输入和多角色回应 | 玩家窗口合并；SocialTurn（一次聊天回应安排）；独立角色任务及后台执行 | 程序按提及和最近发言等规则选择角色，人数可配置；尚无模型参与意愿判断 |
| 情境提示 | 聊天和采访共用人设组装与自然表达；日常与认真提问按内容和表达意愿展开 | 采访只写作者候选，不产生正式消息、内心、关系、状态或记忆；生成质量仍需作者审核 |
| 对话输入 | 人物正文、可见历史、自身历史 Thought（私有内心记录）、状态、关系、摘要和记忆 | 各任务保存独立输入；其他角色不能读取自身私有内心记录 |
| 模型与记忆工具 | 真实供应商、任务路由、调用预算、memory_search（记忆查询） | 模型自行决定是否发言和查询；不要求每轮调用工具 |
| 角色状态与关系 | 分类历史、活动状态期限、好感／信任／依恋算法及多目标事实提交 | 当前反思的关系消费者处理普通互动；支持、冲突和承诺分类消费者尚未接入 |
| 记忆材料与查询 | 精确归段、摘要消费、长期页、实体关系、全文检索及索引重建 | 读取仍受社群、角色和来源可见范围约束；不包含正式向量检索或对话前自动预检索 |
| 三种主要反思 | 段反思、连续性压缩、长期记忆整理的节点执行、审核、保存；本地管理接口手动安排 | 自动封段、扫描材料及持续调度尚未接入；日记和认识刷新没有管理执行入口 |
| 任务恢复 | 完整失败分类与动作、统一等待和耗尽、审核提示、执行历史、心跳、过期租约与进程恢复；无最终审核结果的失败图重新启动 | 复用冻结输入和成功产物；部分成功后的补充运行尚未接入 |
| 诊断与维护 | 健康检查、日志、范围化追踪、管理对象发现、任务与记忆查询、封段及反思操作、范围化材料导出、CLI（命令行工具）及数据库备份 | [管理接口](reference/management-api.md) 供本地测试管理使用；没有账户访问控制 |

公开聊天请求返回后，后台独立生成角色回应；当前通过 HTTP 轮询读取消息和轮次。没有正式实时推送或逐字输出接口。服务采用本地单进程与 SQLite 持久化，具体接入方式见 [接入指南](guides/frontend-integration.md)。

系统消息已有独立来源类型、存储和读取支持，但自动系统通知及活动结果通知未接入。角色回复不会自动触发无限连续接话。

## 2. 有设计或部分结构、尚未完成的能力

| 能力 | 已有内容 | 尚缺内容 |
|---|---|---|
| 自定义人物后续能力 | 创作、固定资源与独立实例已经接入 | 作者材料反思、运行模式、人物共享及已有实例重置 |
| 群聊参与与角色接话 | 规则排序、参与决定、独立任务和合法沉默 | 内容相关的参与意愿、角色发言触发后续轮次、新消息观察及有限连续接话；当前同轮任务分别使用原输入 |
| 角色运行模式与作者初始记忆 | 当前初始记忆直接复制；摘要及完整反思已有部分实现 | 简单／完整模式策略、段摘要搜索、故事与采访正式来源和初始化反思；RSI 为未来方向 |
| 主动开口、话题卡与事件卡 | 已保存旧设计原文及迁移草案 | 正式话题池、事件模板与实例、主动信号、动机评估和发送规则；当前均未实现 |
| 日记 | 图定义、行动契约及存储 | 游戏日材料读取、专属提示、触发、审核、事实消费者及清理协调 |
| 关系态度、状态概括和核心记忆刷新 | 图定义、候选契约及派生视图存储 | 正式事实变化输入、刷新条件、专属提示、节点输入和事实消费者 |
| 持续记忆整理 | 三种主要反思可以执行 | 自动材料调度、部分成功补做及真人材料质量验收 |
| 角色长期生活 | 身份、状态、关系和记忆基础 | 模型参与意愿、主动交流及生活运行规则 |
| Activity（活动） | 独立任务、观察、权威状态和聊天并行的完整接入设计 | 活动模块、接口、任务队列、表和具体玩法 |

日记、认识刷新及长期记忆质量需要真实互动材料支持。当前安排是先通过真人使用积累材料，再据此完善对应能力；现有结构和技术验证不能代替内容质量验收。

## 3. 验证范围

2026-10-03 的代码与管理接口验证记录如下；后续专项验收记录见本节末尾。

本次真实验证使用已登记的 DeepSeek 对话路由和 GLM 反思路由，模型登记与密钥未修改。

- 本地测试：109 项通过，12 项模型测试未参加该批运行。新增管理接口验证覆盖对象发现、分页、任务关联、消息受众、追踪归属、封段重复请求、失败图重新启动、记忆查询和范围化导出。
- 真实模型场景：分批运行 12 项通过。原有 8 项覆盖后台任务、历史内心、受众、配置失败隔离、接口、进程恢复、合法沉默及完整双角色反思；两项修正后的查询测试验证合法选择和真实来源；两项管理模型场景验证内心清除后的所有管理读取路径，以及通过 HTTP 安排三种反思、真实后台执行、记忆查询与导出。原有反思场景继续验证复用成功产物、长期页与实体保存、第二轮连续摘要链。
- 构建与参考：安装包构建、静态检查、生成接口与源码导航检查、数据库参考检查及正式文档链接检查通过。本轮没有重做源码目录外安装后的完整运行验证。
- 质量验证：长期记忆整理尚未完成足够真人素材下的质量测试。摘要是否保留重点、关系与状态是否恰当、长期页是否有用，需要独立评价。

查询测试已接受合法沉默与自主查询，保留身份、合法输出、停止原因、结果恢复和私人范围断言；实际调用时通过真实捕获核对来源及版本。工具能力另有独立的真实执行验证。提示基线测试使用归档后的实际文件路径，配置模板读取明确使用 UTF-8。

固定提示及六类已实现节点细则已完成逐字核查；回复来源、沉默和多目标身份的必要扩展在 [提示契约](design/character-prompt-contracts.md) 明确定义。日记和视图专属提示仍未实现。详细验证方法见 [验证指南](guides/verification.md)。

### 玩家 API 修正验收

玩家 API 修正已完成，包含身份与社群发现、自身会话概要、当前参与者、最新历史与引用、服务端阅读位置、成员请求幂等及管理完整列表。124 个非模型场景分批通过，真实 HTTP 双角色公共及私有聊天场景通过；静态、契约与参考、文档链接和前端类型检查通过。新迁移为版本 4，用户实际数据库没有升级。完整范围见 [接口实施记录](../../docs/02-api-boundary-review.md)。

### 会话发送范围简化验收

2026-10-05：新发送统一使用会话成员范围，删除消息级 `visibility` 与 `recipients` 输入。历史私有记录、已有轮次范围及实际成员区间继续保留；数据库结构和用户实际数据未修改。

125 项非模型测试通过。真实 HTTP 群聊与独立私聊、历史私有轮次执行及管理投影两项模型场景通过。扩展双角色反思场景未通过：段反思及连续摘要已完成，长期记忆的 `graph_extract` 节点调用 GLM 连续两次超时，每次 120 秒，完整反思链未完成验收。该项保留原预算、超时及断言。

静态检查、接口与数据库参考、源码导航、48 份正式文档链接、前端接口类型生成和类型检查通过。

### 自定义角色基础验收

2026-10-05：默认模板、引导、采访题库、所有者草稿、三种 AI 辅助、独立候选、固定版本、复制和实例化已完成。故事及采访仅保存原文，运行模式、初始材料消化与已有实例重置继续安排在后续任务。

130 项非模型测试通过；两项真实模型专项通过，覆盖三种创作模式、手工与 AI 人物的私聊和群聊、实际正文与版本、生成期间写入、过期候选拒绝，以及创作和聊天共享并发额度。新增迁移 5 的真实升级验证保留玩家、社群、角色、消息、任务输入和记忆；没有升级用户实际数据库或修改模型密钥。

静态检查、安装包构建、生成契约、数据库参考、源码导航和正式文档链接检查通过。前端接口类型已重新生成；前端类型检查仍失败于已有 MessageView 引用，当前接口使用 PlayerMessageView，本轮之前的 OpenAPI 也已采用该名称。需由前端接入工作修正对应引用。

### 三阶段人物创作验收

2026-10-06：基础、故事、采访的顺序与复核、四种类型化候选、独立接受、默认十五题、十至十五题选题、每批一至五题、冻结采访依据、三份正文校准及手工审核已接入。作者可以在基础或故事阶段结束；修改上游保留原文并要求复核，校准接受保持材料的确认状态。直接完善 0005，最高结构版本保持 5，用户实际数据库与模型密钥未修改。

133 项非模型测试通过，覆盖手工流程、原文保存、阶段依赖、选题边界、复核、来源校验、复制与固定，以及从结构 4 升级到 5 的真实资料保存。四项真实模型专项分批通过结构和执行检查，包含四操作、三批采访、校准接受、手工与辅助人物私聊和群聊、过期候选、生成期间写入、共同并发额度、两种性格采访、明确冲突拒绝接受、日常及认真提问和合法沉默。采访前后逐表检查，未生成正式消息、Thought、实例、关系、状态或记忆。

人工检查中，内向人物较少主动交流，热情人物更愿意展开细节；认真提问比日常回应更充分，明确冲突能引用 description 与 profile。模型仍会在既有经历周围补出未写入材料的细节，这项内容质量没有完成严格事实忠实性的验收；已有共同规则允许主动讲述未记录经历，情境提示已明确认真提问与采访的事实限制，后续润色仍需使用真实材料检查。候选结构合法不代表内容已获作者认可。

静态检查、安装包与四份提示资源、接口与数据库参考、源码导航和文档链接通过。前端接口类型已生成，类型检查仍受既有 MessageView 引用影响，没有发现本轮新增类型错误。临时实施计划已删除；长期规则见 [人物创作设计](design/custom-character-authoring.md)。

## 4. 后端后续工作

本节统一维护当前后端开发顺序。自定义角色基础与三阶段创作已经完成，接下来实现简单与完整模式、摘要检索及自动整理。人物创作结构在本阶段 0005 内定稿，最高数据库版本保持 5。完整规则见 [人物创作设计](design/custom-character-authoring.md)，其余讨论见 [设计草案](design-drafts/README.md)。

### 4.1 开发顺序与依赖

| 顺序 | 工作 | 完成范围与依赖 |
|---|---|---|
| 1（完成） | 自定义角色基础 | 原文保存、默认模板、AI 候选、归属、固定版本及独立实例创建已实现；后续背景变更需重新初始化，已有实例重置待专项设计 |
| 1.1（完成） | 三阶段创作与人设校准 | 分阶段生成、接受与确认；四套提示；默认十五题与分批采访；共同扮演及认真提问指导；只校准三份正文，作者可手工完成全过程 |
| 2（下一步） | 简单与完整模式、摘要检索及自动整理 | 人设复杂度与运行模式独立；简单模式运行段摘要和压缩，接入摘要检索、自动封段与调度；完整模式使用已接入流程，日记与认识刷新仍需实现 |
| 3 | 群聊参与判断与角色接话 | 内容相关的参与判断、角色消息触发新轮次、后续任务读取新内容；明确玩家插话、合法沉默、停止规则及预算 |
| 4 | 初始记忆消化与完整记忆完善 | 作者故事与采访成为正式来源；简单模式生成背景摘要，完整模式整理长期记忆；补齐部分成功补做、关系证据分类、认识刷新及日记 |
| 5 | 游戏执行与经历接入 | 四人飞行棋规则、独立行动任务、聊天中的活动观察、事件反应与可追溯记忆；不依赖日记完成 |
| 6 | 主动开口、话题池及事件体系 | 无新消息时发起交流，同池主动候选与玩家建议，事件模板及实例；基于正式可见来源，具体规则待讨论 |
| 未来实验 | 智能角色 RSI | 保留研究方向，当前不实现学习或训练结构，也不公开可用入口 |

真人材料与反馈持续积累，内容质量验收贯穿各项工作。第 4 项可分别交付；游戏在所需来源和执行契约完成后即可推进。主动开口不要求所有旧剧情和生活事件全部实现。实施前确定对应正式契约与验收要求。

| 活动执行 | 具体玩法和活动接口契约 | 活动任务与聊天独立；合法轮序、观察范围、过期操作、重启及真实活动来源完整验证 |
