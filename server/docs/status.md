# 后端能力与实现状态

更新日期：2026-10-04；软件版本：`0.1.0`。

本文件记录后端当前能力、验证范围及后端待办。完整业务规则以 [设计目录](README.md) 为准，实际请求和响应以 [接口参考](reference/http-api.md) 为准。整体阶段和前后端协作安排见 [项目推进计划](../../docs/01-project-roadmap.md)。

## 1. 当前可使用的能力

| 能力 | 实际实现 | 使用边界 |
|---|---|---|
| 社群、玩家和角色 | 创建与持久化；人物模板创建独立实例；公开接口 | 同一模板的不同实例分别保存状态、关系和记忆；没有玩家账户认证 |
| 私聊和群聊 | 创建会话、加入、离开、公共消息、指定受众、提及及回复 | 读取按成员区间和实际受众过滤；重新加入不能获得离开期间的消息 |
| 连续输入和多角色回应 | 玩家窗口合并；SocialTurn（一次聊天回应安排）；独立角色任务及后台执行 | 程序按提及和最近发言等规则选择角色，人数可配置；尚无模型参与意愿判断 |
| 对话输入 | 人物正文、可见历史、自身历史 Thought（私有内心记录）、状态、关系、摘要和记忆 | 各任务保存独立输入；其他角色不能读取自身私有内心记录 |
| 模型与记忆工具 | 真实供应商、任务路由、调用预算、memory_search（记忆查询） | 模型自行决定是否发言和查询；不要求每轮调用工具 |
| 角色状态与关系 | 分类历史、活动状态期限、好感／信任／依恋算法及多目标事实提交 | 当前反思的关系消费者处理普通互动；支持、冲突和承诺分类消费者尚未接入 |
| 记忆材料与查询 | 精确归段、摘要消费、长期页、实体关系、全文检索及索引重建 | 读取仍受社群、角色和来源可见范围约束；不包含正式向量检索或对话前自动预检索 |
| 三种主要反思 | 段反思、连续性压缩、长期记忆整理的节点执行、审核、保存；本地管理接口手动安排 | 自动封段、扫描材料及持续调度尚未接入；日记和认识刷新没有管理执行入口 |
| 任务恢复 | 心跳、过期租约、进程恢复；无最终审核结果的失败图重新启动 | 复用冻结输入和成功产物；部分成功后的补充运行尚未接入 |
| 诊断与维护 | 健康检查、日志、范围化追踪、管理对象发现、任务与记忆查询、封段及反思操作、范围化材料导出、CLI（命令行工具）及数据库备份 | [管理接口](reference/management-api.md) 供本地测试管理使用；没有账户访问控制 |

公开聊天请求返回后，后台独立生成角色回应；当前通过 HTTP 轮询读取消息和轮次。没有正式实时推送或逐字输出接口。服务采用本地单进程与 SQLite 持久化，具体接入方式见 [接入指南](guides/frontend-integration.md)。

系统消息已有独立来源类型、存储和读取支持，但自动系统通知及活动结果通知未接入。角色回复不会自动触发无限连续接话。

## 2. 有设计或部分结构、尚未完成的能力

| 能力 | 已有内容 | 尚缺内容 |
|---|---|---|
| 错误分类与恢复诊断 | 统一失败契约、供应商分类与请求重试、执行循环修正、有限任务重试及租约恢复 | 完整恢复决定传递、具体审核及准备错误码、独立修正提示、持久恢复历史及管理查询；详见 [恢复要求](design/errors-and-recovery.md) |
| 日记 | 图定义、行动契约及存储 | 游戏日材料读取、专属提示、触发、审核、事实消费者及清理协调 |
| 关系态度、状态概括和核心记忆刷新 | 图定义、候选契约及派生视图存储 | 正式事实变化输入、刷新条件、专属提示、节点输入和事实消费者 |
| 持续记忆整理 | 三种主要反思可以执行 | 自动材料调度、部分成功补做及真人材料质量验收 |
| 角色长期生活 | 身份、状态、关系和记忆基础 | 模型参与意愿、主动交流及生活运行规则 |
| Activity（活动） | 独立任务、观察、权威状态和聊天并行的完整接入设计 | 活动模块、接口、任务队列、表和具体玩法 |

日记、认识刷新及长期记忆质量需要真实互动材料支持。当前安排是先通过真人使用积累材料，再据此完善对应能力；现有结构和技术验证不能代替内容质量验收。

## 3. 验证范围

最近一次代码与管理接口验证日期为 2026-10-03。

本次真实验证使用已登记的 DeepSeek 对话路由和 GLM 反思路由，模型登记与密钥未修改。

- 本地测试：109 项通过，12 项模型测试未参加该批运行。新增管理接口验证覆盖对象发现、分页、任务关联、消息受众、追踪归属、封段重复请求、失败图重新启动、记忆查询和范围化导出。
- 真实模型场景：分批运行 12 项通过。原有 8 项覆盖后台任务、历史内心、受众、配置失败隔离、接口、进程恢复、合法沉默及完整双角色反思；两项修正后的查询测试验证合法选择和真实来源；两项管理模型场景验证内心清除后的所有管理读取路径，以及通过 HTTP 安排三种反思、真实后台执行、记忆查询与导出。原有反思场景继续验证复用成功产物、长期页与实体保存、第二轮连续摘要链。
- 构建与参考：安装包构建、静态检查、生成接口与源码导航检查、数据库参考检查及正式文档链接检查通过。本轮没有重做源码目录外安装后的完整运行验证。
- 质量验证：长期记忆整理尚未完成足够真人素材下的质量测试。摘要是否保留重点、关系与状态是否恰当、长期页是否有用，需要独立评价。

查询测试已接受合法沉默与自主查询，保留身份、合法输出、停止原因、结果恢复和私人范围断言；实际调用时通过真实捕获核对来源及版本。工具能力另有独立的真实执行验证。提示基线测试使用归档后的实际文件路径，配置模板读取明确使用 UTF-8。

固定提示及六类已实现节点细则已完成逐字核查；回复来源、沉默和多目标身份的必要扩展在 [提示契约](design/character-prompt-contracts.md) 明确定义。日记和视图专属提示仍未实现。详细验证方法见 [验证指南](guides/verification.md)。

## 4. 后端后续工作

| 工作 | 输入或依赖 | 交付与验收 |
|---|---|---|
| 错误分类、重试与恢复功能完善 | [已核实的迁移差距及恢复设计](design/errors-and-recovery.md) | 保留具体错误码和完整动作；原快照不变，按需附修正提示；捕获关闭后仍能查询恢复历史；通过真实错误、次数耗尽及旧租约验证 |
| 真人材料积累与评价 | 已有聊天、管理查询和范围化导出接口 | 持续保存真实互动、来源身份和人工反馈，评价材料与整理内容质量；诊断捕获独立保存 |
| 记忆整理完善 | 真人材料及明确的质量评价 | 验证来源、摘要、长期页和实体质量；实现完整自动调度与部分成功补做；失败不错误推进消费 |
| 日记与认识刷新 | 已验证材料及各专项设计 | 接入完整输入、提示、审核与消费者；自身感受、他人陈述和客观事实保留区别 |
| 长期生活 | 日记、认识及自主行为设计 | 明确参与意愿、主动交流、世界时间和调用预算，验证行为与来源 |
| 活动执行 | 具体玩法和活动接口契约 | 活动任务与聊天独立；合法轮序、观察范围、过期操作、重启及真实活动来源完整验证 |

本表只记录后端职责。具体优先级、前端工作和共同验收阶段统一放在项目推进计划；新增后端功能实施时更新对应设计、接口参考与本文件。
