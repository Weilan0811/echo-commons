# 能力、设计差异与审核状态

更新日期：2026-10-02；基线版本：0.1.0。design 目录定义社群、多角色和活动平台的目标业务规则与完整提示契约。此文说明当前实际能力、差异裁定及下一步代码修复计划。用户已授权按第 3 节顺序修复代码，每项验证后单独本地提交。修改记录统一见 [迁移修复记录](../../docs/09-migration-repair-record.md)。

## 0. 差异判断依据

用户已确认统一标准：确实为了多角色、Activity 或社群实现而产生的差异可以保留；其他行为和提示以原实现为准。原实现依据为改造前提交 `400defb`，必要时与首次仓库基线 `0a14ed4` 交叉核查。

每项差异分别列出保留与恢复的部分。改变目录、服务接口和数据库布局不意味着可以重写角色表达、事实判断、关系算法或失败语义。原实现未完成的能力保持未完成；原文档提出的目标不能直接登记为迁移丢失的已实现能力。字段结构和流程能够正常运行也不能代替原行为核查。

## 2. 差异裁定与修复结果

### D10：固定提示恢复——P0 最高优先级

迁移时对话指导、输出说明、反思节点细则、上下文表达、正式工具提示及部分修正提示被删除或改写。人物资源正文与初始记忆保留，不能据此认定模型实际提示一致。修复前的完整核查及十五项 P0 差异见 [提示逐字核查](../../docs/07-prompt-preservation-audit.md)，原文和完整比较证据一并保存；修复后的结果如下。

固定正文、工具和修正文字已经恢复，并完整比较输出说明及六类节点细则。仅四处字段说明或结构示例因回复来源、沉默和多目标关系变化；发送者、实例及关系目标采用真实身份。三维判断及数值算法保持原规则。实际模型可以选择沉默或不查询工具；两个记忆查询场景没有满足预期，此结果保留在第 4 节。

完整固定正文、当前多角色字段及示例在 server 内的 [角色提示契约](design/character-prompt-contracts.md) 保存。对话字段直接定义 thought、utterance、可选 reply_to_message_id 和独立 silent 结果；关系变化每项直接定义 target、dimension、direction、level。字段说明和示例一致，修复代码时按这份确定的契约实施。额外字段结构说明不能替代业务文字；扩大查询长度、统一放宽 NoOp、将常驻背景或前驱分析当作新证据均不属于必要扩展。

### D01：对话没有读入自身历史 Thought

修复前 ConversationContext 没有读取 Thought。现在按自身已批准发言读取未清除正文，单独保存在 MemoryContext 并计入历史预算；其他角色发言不携带私有正文。真实生成、提交、冻结输入和清除验证通过。补查还恢复了尚未被 digest 覆盖的近期段摘要；范围和预算见 [上下文](design/perspective-and-context.md)。

### D02：冻结连续性批次可以 NoOp 结束

修复前冻结批次可以不保存 digest 而结束。现在节点、图审核和事实服务拒绝缺少必需摘要的段及连续性结果；长期整理仍可合法 NoOp。真实两批摘要链和拒绝路径已经验证，规则见 [连续性设计](design/reflection/continuity-compress.md)。

### D03：失败流程重新启动丢失；部分成功后的补做保持未实现

失败节点导致图失败后，再次正式调度会检查冻结材料，重新激活失败及被中断节点，保留成功产物和已关闭的条件分支。新领取增加尝试及租约代次，旧结果不能提交。已有图级拒绝或过期决定的运行保持终态，具体边界见 [反思执行](design/reflection/execution-model.md#4-生命周期与恢复)。

partial 后另建恢复运行、只补做失败可选分支，改造前没有完整接入，继续保持未实现。过期租约恢复已经存在。

### D04：状态版本行为已核实；保存前文字处理遗漏

模型候选不携带模型读取时状态版本，改造前同样如此。事实写入使用事务内最新记录，当前事务以 BEGIN IMMEDIATE 执行，版本递增、活动状态 24 小时失效及失效后不恢复旧状态已通过真实数据库验证。撤回新增模型候选版本协议的要求。

状态保存前已恢复去除首尾空格，并以处理后的文字比较重复来源；空白文字拒绝。版本递增及 24 小时失效规则保持有效。

### D05：关系漏算怀疑已撤回

当前按目标分组，一次处理该目标全部维度。真实 SQLite 验证同一目标好感和信任均从 50 变为 50.5，重复提交没有重复加分。图级审核限制同一目标维度唯一，候选与事实、审核结果同事务提交；已有图结果阻止同图再次消费不同候选。当前正式调用链没有确认的漏算问题，保留多目标分组，不新增重复内容保护或来源身份框架。

### D06：轮次、系统来源和意图存在契约差异

这项包含不同来源的四个问题，分别裁定：

| 项目 | 依据与当前差异 | 处理决定 |
|---|---|---|
| SocialTurn.pending | 原子规划直接建立 running 或 completed，类型没有 pending | 迁移 0002 已限定三个正式轮次状态，已有数据保留 |
| system 消息来源 | 成员 ActorRef 只表示玩家和角色，消息可有系统来源 | 已恢复独立 SystemSource，存储、观察及公开类型支持该来源；系统无成员和关系资格，自动通知流程仍未实现 |
| EventRef | 原改造方案提出通用引用，当前使用具体来源身份与版本 | 保留明确来源的具体类型；活动接入时定义活动结果引用，不提前加入无消费者的通用层 |
| intent | 新快照有默认空字段，当前没有填充和消费；改造前源码没有意愿生成或消费流程 | 保持未实现，不新增意愿类别或生成流程 |

人物可用状态和任务失败分别保存。原项目专用状态的已批准删除范围继续遵守，代码状态和 SQL 允许值必须一致。

### D07：关系资格有规则，消费者只有普通互动

原段反思 RelationshipFactHandler 同样固定 interaction；当前未增加其他类别消费者，属于原有边界。保留 support、conflict、commitment 的领域规则和朋友、依恋资格，保留多目标关系身份；本轮不新增支持或承诺分类器。数值公式、步长、初始化和资格继续按原算法验证，完整说明见 [角色事实](design/character-state-and-relationships.md)。

### D08：长期文档完整性与独立性

长期设计已分离对象生命周期，补回事实与回忆判断、逐节点职责、材料投影、业务条件及运行例子；原提示全文保存在 server 的正式设计中。开发说明继续索引源码，设计正文解释完整意图。用户确认此次修订方向，修订内容供阅读核验；文档检查不能证明运行代码已经符合设计。

### D09：省略路径与字段分组

新 TOML 分组和包内人物资源属于新平台配置布局，可以保留。修复前省略路径依赖工作目录，部分字段按最终名字验证，可能接受放错组的字段。这些歧义已经消除。

已恢复逐组字段检查；显式及省略的默认文件路径均以设置文件目录解释，默认值与正式模板一致。换启动目录后读取同一文件，结果一致。包内资源和用户模型登记保持有效，规则见 [配置参考](reference/configuration.md)。

### D11：反思节点的信息投影退化

模型节点已恢复按职责选择身份、状态、关系、记忆及材料；完整图快照继续保存用于恢复。模型证据只采用本节点允许来源，前驱分析单独作为背景。关系节点额外获得本次材料中的明确目标身份，系统来源不会进入目标集合。

输入矩阵与真实模型消息已有存储断言，规则见 [反思执行](design/reflection/execution-model.md)。完整输入不能代替逐节点信息选择。

|---|---|---|---|
| R01 | 恢复对话、反思固定提示、工具及修正文字 | 固定正文逐字验证，必要结构扩展有明确记录，真实模型输入符合提示契约 | 已完成；完整固定正文比较与实际请求通过，两个主动查询场景未通过，具体限制见第 4 节 |

## 4. 证据与验证范围

本轮最终本地测试为 103 passed、10 deselected。静态检查、64 份文档链接、源码目录参考、真实数据库参考及公开接口与设置类型参考均通过。构建安装包成功，检查确认新迁移、系统来源类型和完整提示模块均包含在内。本轮没有重新执行源码目录外安装后的完整运行测试。

实际使用用户登记的 DeepSeek 对话路由和 GLM 反思路由，未修改模型登记及密钥。8 项真实模型场景通过：后台执行与追踪、历史内心及冻结输入、受众与退出、配置失败隔离、HTTP 会话、进程终止恢复、合法沉默，以及完整两角色反思。反思场景验证初始两图中断后复用成功产物、连续摘要、长期页和实体保存、第二轮段摘要及前后 digest 链，最终用时 411 秒。

两个对话查询测试没有通过。普通请求中角色选择了合法沉默；明确提及并要求查询时，角色回应但没有调用 memory_search。实际供应商请求包含工具定义与 auto 选择，独立工具读取及私人范围验证通过，反思场景也实际调用了工具。当前固定提示和运行规则不能保证角色在每次请求中主动查询。失败测试保留，未修改业务提示或改成强制工具调用，也未将这些场景计为通过。后续如需改变角色查询行为，应另行确定行为要求。

[验证指南](guides/verification.md) 保留 A01—A32 和本轮必要断言。日记、视图、partial 补充恢复及尚未实现的活动流程保持原范围。当前状态说明实际运行边界，不声明整个目标平台已实现。
