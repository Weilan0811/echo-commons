# 后端能力与实现状态

更新日期：2026-10-27；软件版本：`0.1.0`。

角色表达与记忆整理已经统一个人日常补充和共同事实边界；整理节点使用任务专属规则，相关匹配事实在自动检索和输入裁剪时优先保留。独立诊断支持事实、摘要与认知两组开关，默认关闭；原写作者处理问题反馈，诊断通过后沿用现有审核与保存。迁移 28 保存真实调用步骤及恢复记录，详见[执行规则](design/reflection/execution-model.md#7-整理草稿诊断)与[架构决定](adr/0012-memory-draft-diagnosis.md)。

真实消融包含表达重复生成、固定材料整理、同稿诊断与修正、相关事实保留的撤除对照，以及正式对话到记忆整理再到回忆的完整流程。连接失败后重启复用初稿、已通过草稿复用、重复提交和修改次数上限已验证。提示仍会出现改口与共同往事补写，诊断仍有误报；通过检查的数量不作为文字正确率。

2026-10-27完成整理准则补充对照，共60次真实请求。额外准则未显示稳定质量收益，已恢复任务分离后的校准前提示。表达采用同次私有核查与公开发言、按需检索并精简重复输入；社群世界设定由用户维护。采用决定已归档，新增业务能力待接入。范围与依据见[实施计划3.1.5](../../docs/06-activity-implementation-plan.md#315-最终采用方案与实施顺序)及[实验依据](adr/evidence/20261027-expression-memory.md)。

人物创作已支持确认人物编号、第二步关系材料、社群角色与玩家身份关联，以及初始关系分析和后加入成员的关系建立。百科整理通过独立后端工具生成候选，人物和材料需要作者确认；实现范围见[人物关系与初始化](design/character-people-and-initialization.md)。最初的“基沃托斯”验证使用星野和日富美，两位角色均完成真实模型完整初始化；原数据库现已更新为八人测试社群，材料和报告保存在 `server/data/verification/kivotos/` 与 `kivotos-eight/`。

百科整理、普通基础创作和最终校准共用三份人设文档的职责说明：保留代表性说话例句，一般相处方式与具体人物关系分别组织。“测试社群2”已通过真实模型完成星野、日富美的百科创作及白洲梓的普通创作和完整初始化。逐阶段材料与全部记忆、认知、关系文本保存在 `server/data/verification/quality-review-20261020/`。文字核验发现核心记忆人物归属错误、关系态度时态不准、人物设定重复故事及部分无依据扩写；初始化成功不代表文字质量验收通过。

普通群聊已接入本地参与判断。规则安排候选，一次角色任务固定共同上下文与模型方式；本地模型选择参与、沉默或进一步理解，conversation 生成和提交表达。判断结果独立保存，恢复时复用；一次候选不因多个调用重复计算额度。主动开场和私聊保持原流程。默认开关仍为关闭，规则见[智能参与判断](design/conversation-and-social.md#41-智能参与判断)。

固定“基沃托斯”社群现有七名角色和玩家老师，采用完整记忆模式。九种场景的三组真实对照共二十七场：修改前普通调用37次，修改后关闭本地模型36次，开启本地模型27次并增加48次本地判断；后两组总耗时分别约61秒、102秒。本地判断选择参与26次、沉默22次，本批没有自然触发进一步理解。完整聊天、内心、判断和实际调用保存在本地 `server/data/verification/social-judgment-20261021/群聊对照全文.md`。缺失前情被当真、无依据补写细节和部分重复接话仍是文字质量问题。

本地决策接入验证（2026-10-20）：331 项非模型回归通过；决策客户端与主动对话的 13 项真实模型场景通过，包含实际 8090 服务的三种问题、推理控制、无匹配信号和关闭流程。本地报告为 `server/data/verification/decision-all.xml` 与 `decision-live-regression.xml`。

### 长期事实与角色认知

日常长期整理读取原始可见消息与自身 Thought，作者初始化读取可知作者原文。`memory_organize.v5` 使用事实提取、语义审核、认知形成和聚合四节点；模型只填写正文和材料编号，程序维护操作、身份、版本、时间和逐项依据。事实与认知分别保存，正文保留陈述归属、计划与不确定性，不设置细分类别。`view_refresh.v3` 表达已有有效记录，核心保留一份有支持引用的正文。

迁移 19 删除旧混合页与来源表，预置原文保存为作者材料，完整模式按原始资料重新准备。旧协议运行停止，原始消息、Thought、状态历史、关系数值及审计保留。正式数据库仍为版本 18，本轮升级及重建使用真实备份副本。两人的完整重建及阶段恢复已验收，正文质量限制见第 3 节。
