# 轮次与参与决定

实现位于 `modules/social/`。SocialTurn 表示对同一受众的一次多人回应安排，保存输入批次、共享消息上限和最终状态。ParticipationDecision 为每个候选角色保存选择原因、顺序、执行状态与结果。

TurnPlanner 封闭到期玩家批次，并在短事务中建立轮次、参与决定与独立角色任务。确定性规则检查角色可用状态、成员区间、是否可见全部输入和 responder 能力；提及优先，回应人数受配置限制。其他角色保存明确沉默原因。当前没有模型驱动参与意愿评价。

TurnCompletion 根据所有参与者终态结束轮次；失败、取消与沉默均可完成。角色输出形成已封闭的零窗口 InputBatch，保存所属轮次和因果来源，当前不会自动创建连续接话。

TurnQuery 对读取玩家使用共同观察规则，只返回玩家可见全部输入的轮次。公开类型包含轮次状态与参与原因，排除私有快照、Thought 和内部失败内容。

角色实际生成、审核与消息写入归 [conversations](conversation.md)；存储字段见 [数据库](../database-design.md)。
