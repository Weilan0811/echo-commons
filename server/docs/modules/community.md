# 社群与玩家

实现位于 `modules/communities/`。CommunityService 创建社群、登记玩家、管理成员以及暂停、恢复、归档。社群拥有运行时间、时区与版本；Player 是实际输入的玩家身份，ActorRef 明确区分玩家和角色。

社群范围与玩家身份分别保存。相同创建标识和内容重复提交会返回原对象，内容冲突报告明确错误。角色实例归属某一社群，初始化完成后由正式服务加入社群；玩家通过明确加入入口成为成员。

社群暂停影响任务领取和正在执行的租约资格；归档取消相关未完成对话任务，避免后续输入永久等待。状态变化通过正式业务服务与任务生命周期协作。HTTP 提供创建社群、登记玩家与加入社群，内部生命周期服务供编排使用。

API 位于 api/routes.py 与 api/schemas.py，纯类型位于 domain.py，持久化位于 repository.py。字段与复合引用见 [数据库](../database-design.md)。
