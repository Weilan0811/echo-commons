# Echo Agent Contract 变更日志

- 0.6.1-draft（2026-09-26）：调整日常回应指引，让角色按自己的想法说话，减少每轮结尾提问。
- 0.6.0-draft（2026-09-11）：移除面向模型的内部协议、能力目录和实现术语，改为以生活视角、认知边界和自然反应组织通用对话前提；工具定义改由 Provider 原生字段传递。
- 0.5.0-draft（2026-09-09）：把通用契约改写为简短的对话前提、认知来源、行动权限和提案协议；将“如何像角色说话”的负面清单继续移出通用层，给角色 Profile 留出自然表达空间。
- 0.4.0-draft（2026-09-09）：将通用资源收敛为协议、认知边界、工具权限和 Runtime 提案边界；不再承担角色语言风格清单。
